# Pol-Language

آموزشگاه زبان پل — سایت فارسی راست‌به‌چپ با طرح سرمه‌ای، کرم و طلایی.

این مخزن شامل ظاهر HTML سایت، تصاویر و فونت‌ها، کد سامانه آموزشی Django و راهنمای نصب است.

## شروع کار

- برای دیدن ظاهر سایت، `index.html` را در مرورگر باز کنید. پوشه `assets` و فایل `site-config.js` باید کنار آن باشند.
- برای اجرای سامانه روی ویندوز، Python 3.12 یا جدیدتر نصب کنید و `server/start-windows.bat` را اجرا کنید. نشانی محلی و رمز حساب‌های آزمایشی در پنجره فرمان نمایش داده می‌شوند.
- برای نصب روی سرور و اتصال دامنه، [راهنمای کامل](GUIDE-fa.html) و [راهنمای بخش سرور](server/README-fa.md) را بخوانید.

## فایل‌های پروژه

| مسیر | کاربرد |
|---|---|
| `index.html`، `assets/` و `site-config.js` | نمایش صفحه اصلی از ریشه مخزن |
| `public_html/` | فایل‌های آماده بارگذاری در پوشه عمومی هاست |
| `server/` | ثبت‌نام و ورود، پنل دانشجو، استاد و مدیر، کلاس‌ها، نمره، حضور‌وغیاب، پیام و تیکت |
| `deploy/` | تنظیمات اجرای سایت و پنل با Docker و Caddy |
| `source/` | فایل‌های قابل ویرایش و سازنده خروجی HTML |

## وضعیت امکانات

جست‌وجو و فیلتر دوره‌ها، جزئیات دوره و تعیین سطح اولیه در نسخه HTML کار می‌کنند. نتیجه آزمون این صفحه موقت است و در حساب دانشجو ذخیره نمی‌شود. پنل‌های داخل نسخه HTML پیش‌نمایش هستند.

ثبت‌نام، حساب‌های واقعی، ذخیره نتایج، مدیریت کلاس و سایر امکانات سامانه به اجرای پوشه `server` و پایگاه داده نیاز دارند. افزودن کد به گیت‌هاب به‌تنهایی سرور Django را راه‌اندازی نمی‌کند. ورود گوگل، پرداخت و پیشنهاد تمرین با هوش مصنوعی به تنظیم حساب‌ها و بررسی اتصال واقعی نیاز دارند. کلاس آنلاین از لینک سرویس جلسه استفاده می‌کند.

نام و تصویر استادان، دوره‌ها، برنامه و شهریه‌های نمونه باید با اطلاعات تأییدشده آموزشگاه جایگزین شوند.

## اتصال صفحه اصلی به سامانه

بعد از راه‌اندازی سرور، `backendOrigin` را برابر مبدأ HTTPS پنل، مانند `https://panel.example.com`، قرار دهید:

- در نسخه ریشه مخزن: `site-config.js`
- در بسته مناسب هاست: `public_html/site-config.js`
- برای بازسازی خروجی‌ها: `source/site-config.json`

متغیر `POL_SITE_ORIGIN` در سرور باید با مبدأ واقعی صفحه اصلی مطابقت داشته باشد. جزئیات نصب در راهنما آمده است.

## ساخت دوباره خروجی

از ریشه مخزن اجرا کنید:

```bash
python source/build.py
```

این فرمان پوشه `public_html/` و فایل مستقل `Pol-Language.html` را می‌سازد. برای به‌روزرسانی نمایش از ریشه مخزن، محتویات `public_html/` را نیز در ریشه کپی کنید. فایل مستقل به دلیل تکرار تصاویر و فونت‌ها در مخزن قرار نگرفته و با همین فرمان قابل ساخت است.

## بررسی عملکرد

بررسی منطق صفحه HTML:

```bash
node source/check-logic.cjs
```

بررسی سرور پس از نصب `server/requirements.txt`، در محیط توسعه:

```bash
cd server
POL_DEBUG=1 python manage.py test
```

هنگام افزودن این نسخه، هر ۱۷ آزمون سرور و بررسی منطق فیلتر، تعیین سطح و مسیر اتصال به پنل موفق بودند. اتصال واقعی سرویس‌های بیرونی و نصب روی سرور مقصد هنوز انجام نشده است.

تنها محتویات `public_html/` را در پوشه عمومی هاست قرار دهید. فایل `.env`، پایگاه داده، نسخه‌های پشتیبان و کلیدهای سرویس‌ها باید در محیط خصوصی سرور نگهداری شوند. فایل‌های `.env.example` الگوی خالی تنظیمات هستند.
