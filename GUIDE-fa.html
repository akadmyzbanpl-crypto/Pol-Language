POL LANGUAGE CENTER · HTML EDITION 0.4

سایت پل را روی دامنه خودت منتشر کن.

نسخه HTML با طراحی سرمه‌ای، کرم و طلایی؛ همراه با کد پنل‌ها و راهنمای اتصال.

اول، طرح را ببین

فایل public_html/index.html را باز کن. این نسخه همراه با پوشه تصاویر و فونت‌ها کار می‌کند. فایل Pol-Language.html که جداگانه تحویل شده، نسخه تک‌فایلی همین طرح است و دارایی‌ها را داخل خودش دارد.

در صفحه اصلی می‌توانی دوره‌ها را جست‌وجو و فیلتر کنی، جزئیات هر دوره را ببینی، آزمون اولیه ۱۲ پرسشی را انجام بدهی و از بخش ورود، نمونه پنل دانشجو، استاد و مدیر را باز کنی.

نمونه پنل‌ها اطلاعات ثبت نمی‌کنند و آزمون داخل HTML نتیجه رسمی یا ذخیره‌شده در حساب نیست. ثبت‌نام، پرداخت، پیام‌رسانی و پنل واقعی با اجرای بخش سرور فعال می‌شوند.

داخل بسته چه فایل‌هایی هست؟

فایل یا پوشهکاربرد
public_html/نسخه مناسب انتشار روی هاست؛ صفحه HTML، تصاویر، فونت‌ها، کد صفحه و خطای ۴۰۴.
public_html/site-config.jsاطلاعات تماس، نشانی پنل، اطلاعات اولیه دوره‌ها و وضعیت نمایش نمونه‌ها؛ هیچ کلید محرمانه‌ای در آن قرار نده.
server/کد Python/Django برای حساب‌ها، کلاس‌ها، شهریه، پنل‌ها، تیکت و تعیین سطح ذخیره‌شونده.
deploy/تنظیمات Docker و Caddy برای صفحه اصلی روی دامنه و سامانه روی زیردامنه.
source/فایل‌های قابل ویرایش و سازنده خروجی‌ها؛ بدون نیاز به کتابخانه اضافی Python.
server/README-fa.mdجزئیات اجرای محلی، پایگاه داده، پرداخت، گوگل، هوش مصنوعی و پشتیبان‌گیری.

روش اول: انتشار HTML روی هاست معمولی

  1. دامنه را در پنل هاست اضافه کن و پوشه اصلی همان دامنه، یعنی Document Root، را پیدا کن. برای دامنه اصلی اغلب public_html است؛ مسیر نمایش‌داده‌شده در پنل را ملاک بگیر.
  2. از فایل‌های فعلی سایت، اگر وجود دارند، نسخه پشتیبان بگیر. سپس فقط محتویات پوشه public_html این بسته را در پوشه دامنه بارگذاری کن؛ index.html باید مستقیماً در ریشه همان دامنه باشد.
  3. دامنه را با مقادیر DNS اعلام‌شده توسط میزبان وصل کن. اگر میزبان Nameserver می‌دهد، همان مقادیر را استفاده کن؛ اگر اتصال مستقیم با IP است، رکورد A دامنه را روی IP اعلامی سرور قرار بده.
  4. SSL دامنه را از پنل میزبان فعال کن و سپس انتقال به HTTPS را فعال کن. نشانی سایت را با https:// باز کن.

مرجع مسیر پوشه و بارگذاری: راهنمای رسمی File Manager سی‌پنل؛ مدیریت دامنه و HTTPS: راهنمای رسمی Domains.

پوشه‌های server، deploy و source را در فضای عمومی هاست نگذار. برای انتشار سریع فقط یک فایل نیز می‌توانی نسخه مستقل Pol-Language.html را به نام index.html بارگذاری کنی؛ نسخه دارای پوشه دارایی‌ها برای ویرایش و کش مرورگر مناسب‌تر است.

با این روش، ظاهر سایت و تعامل‌های داخل صفحه منتشر می‌شوند. هاست صرفاً HTML/PHP، برنامه Python همراه بسته را اجرا نمی‌کند.

روش دوم: سایت و سامانه کامل روی سرور

این مسیر برای یک سرور لینوکسی دارای Docker و Docker Compose آماده شده است. دامنه اصلی صفحه HTML را نمایش می‌دهد و زیردامنه panel سامانه دانشجو، استاد و مدیر را اجرا می‌کند.

نمونه نشانیکاربرد
example.comصفحه HTML معرفی و فهرست دوره‌ها
panel.example.comثبت‌نام، ورود، کلاس‌ها، سفارش و مدیریت
  1. کل پوشه پروژه را خارج از پوشه عمومی وب روی سرور قرار بده.
  2. رکورد A دامنه اصلی و زیردامنه پنل را به IP همین سرور وصل کن. پورت‌های ۸۰ و ۴۴۳ باید برای وب قابل دسترس باشند. IPv6 را فقط در صورت داشتن نشانی درست سرور تنظیم کن.
  3. از ریشه پوشه پروژه، دستور زیر را با دامنه واقعی خودت اجرا کن:
python3 source/setup-domain.py example.com panel.example.com

این دستور تنظیمات اولیه دامنه، کلید تصادفی سرور و اتصال صفحه به پنل را می‌سازد؛ تغییری در DNS نمی‌دهد و چیزی منتشر نمی‌کند. اگر deploy/.env از قبل وجود داشته باشد، برای حفظ تنظیمات نصب قبلی آن را بازنویسی نمی‌کند. برای نصب موجود، مقادیر فعلی را دستی و هماهنگ ویرایش کن.

سپس سرویس‌ها را اجرا و حساب مدیر را بساز:

cd deploy
docker compose up -d --build
docker compose exec web python manage.py createsuperuser
docker compose exec web python manage.py check --deploy

پس از آماده‌شدن سرویس، در https://panel.example.com/system-admin/ با حساب مدیر وارد شو. دوره واقعی، مدرس، شهریه، ظرفیت، جلسات و زمان‌بندی را ثبت کن و گزینه انتشار دوره را فعال کن. برای سامانه عمومی داده‌های آزمایشی نساز.

Caddy پس از اتصال درست دامنه‌ها و دسترسی شبکه، صدور و تمدید گواهی HTTPS و انتقال از HTTP را مدیریت می‌کند. صفحه اصلی از فایل‌ها و پنل از برنامه Django پاسخ داده می‌شود. مستندات HTTPS خودکار و سرو فایل در Caddy.

تغییر دوره‌های منتشرشده در پنل هنگام بارگذاری دوباره صفحه اصلی دریافت می‌شود؛ کش پاسخ حداکثر ۶۰ ثانیه است. فقط اطلاعات عمومی دوره و نام نمایشی مدرس فعال دریافت می‌شود. ثبت‌نام و محاسبه مبلغ در خود سامانه انجام می‌شود.

اطلاعات آموزشگاه و اتصال پنل را تنظیم کن

برای ویرایش مستقیم نسخه هاست، فایل public_html/site-config.js را باز کن. برای ساخت مجدد هر دو نسخه، همین تغییرات را در source/site-config.json بده و سپس python3 source/build.py را اجرا کن. ساخت مجدد از فایل JSON، خروجی هاست را بازنویسی می‌کند.

گزینهمقدار مورد نیاز
backendOriginمبدأ دقیق پنل با HTTPS، مانند https://panel.example.com؛ بدون مسیر اضافی. خالی‌بودن یعنی پنل متصل نیست.
phone / email / addressتلفن با رقم انگلیسی، ایمیل و نشانی واقعی آموزشگاه. مقادیر اولیه عمداً خالی‌اند.
sampleModeبرای نمایش طراحی و اطلاعات آزمایشی true است. پس از تکمیل اطلاعات واقعی روی false قرار بده. با دریافت موفق فهرست سرور، وضعیت محیط سرور ملاک می‌شود.
coursesفهرست اولیه و جایگزین هنگام قطع اتصال. عنوان، توضیح، برنامه، سطح، تعداد جلسه و شهریه به تومان قابل ویرایش‌اند. پاسخ سرور متصل، اطلاعات منتشرشده را جایگزین می‌کند.
serverPathبرای اتصال دستی هر دوره به مسیر واقعی مانند /courses/7/؛ هنگام دریافت فهرست سرور خودکار مقدار می‌گیرد.
teachersمعرفی مدرس‌های واقعی در حالت مستقل. تصاویر همراه بسته ساختگی و مخصوص نمونه‌اند؛ برای مدرس واقعی بدون عکس، حرف اول نام نمایش داده می‌شود.
googleEnabledفقط پس از تنظیم ورود گوگل در سرور روی true قرار بده.

اگر پنل را جدا از این بسته نصب کرده‌ای، در محیط سرور نیز POL_SITE_ORIGIN=https://example.com را با مبدأ دقیق صفحه اصلی تنظیم کن و سرور را دوباره اجرا کن. این تنظیم اجازه خواندن فهرست عمومی را می‌دهد؛ دسترسی کاربران همچنان در سرور بررسی می‌شود.

کلید درگاه، رمز مدیر، کلید گوگل و کلید هوش مصنوعی در HTML یا site-config.js قرار نمی‌گیرند. مقادیر محرمانه فقط در محیط بخش سرور هستند.

فعال‌کردن فروش و ورود واقعی

حساب‌های دانشجو با ثبت‌نام عادی ایجاد می‌شوند. مدیر نقش استاد و مدیر را تعیین می‌کند. کلاس‌های آنلاین از لینک HTTPS ثبت‌شده توسط استاد استفاده می‌کنند؛ سرویس تماس تصویری باید جداگانه فراهم باشد.

درگاه زرین‌پال، ورود گوگل و پیشنهاد تمرین هوش مصنوعی آداپتور قابل تنظیم دارند. اطلاعات حساب سرویس‌ها، نشانی بازگشت و کلیدها در راهنمای server/README-fa.md توضیح داده شده‌اند. تا قبل از فعال‌سازی حساب پذیرندگی، پرداخت اینترنتی واقعی فعال نیست. نتیجه آزمون داخل HTML به عنوان نمره معتبر وارد حساب نمی‌شود؛ برای ثبت نتیجه، آزمون سمت سرور اجرا می‌شود.

پیش از شروع فروش، مسیر ثبت‌نام، سفارش، تأیید پرداخت و دسترسی به کلاس را با حساب واقعی آموزشگاه بررسی کن. بکاپ پایگاه داده و محل ذخیره اطلاعات نیز در راهنمای سرور توضیح داده شده است.

لوگوی اصلی آموزشگاه حفظ شده است. تصاویر مفهومی و پرتره‌های نمونه برای این طرح تولید شده‌اند؛ متن تولید تصاویر در source/assets/asset-prompts.json و مجوز فونت در source/assets/OFL.txt قرار دارد.
