آموزشگاه زبان پل — نسخه HTML مستقل — ۰.۴

برای دیدن طرح:
فایل public_html/index.html را باز کنید.
نسخه تک‌فایلی Pol-Language.html نیز جداگانه تحویل شده است؛ تصاویر، فونت‌ها و کدهای آن داخل همان فایل هستند.

برای انتشار ظاهر سایت روی هاست معمولی:
فقط محتویات پوشه public_html را در پوشه اصلی دامنه قرار دهید.
راهنمای مرحله‌به‌مرحله را از فایل GUIDE-fa.html باز کنید.

برای اجرای کامل ثبت‌نام، پنل‌ها و پرداخت:
کد سرور در پوشه server و تنظیمات انتشار یکپارچه در پوشه deploy قرار دارد.
هاست ساده HTML برای اجرای بخش Python کافی نیست. سرور دارای Python یا Docker لازم است.
پوشه‌های server و deploy و source را در فضای عمومی هاست قرار ندهید.

تنظیمات قابل ویرایش:
public_html/site-config.js : آدرس پنل، اطلاعات تماس، دوره‌ها، نمایش اطلاعات نمونه
source/site-config.json : همین تنظیمات برای ساخت مجدد هر دو خروجی
source/build.py : سازنده HTML با Python استاندارد، بدون کتابخانه اضافی

نام و تصاویر استادان، برنامه‌ها، شهریه‌ها و اطلاعات نمونه پنل‌ها باید با اطلاعات واقعی آموزشگاه جایگزین شوند.
پرداخت، گوگل و سرویس هوش مصنوعی به تنظیمات حساب‌های واقعی نیاز دارند.
هیچ دامنه یا هاستی در این مرحله خریداری یا متصل نشده است.
